原理与结论

怎么做单变量对照？

比较 A 与 B、C 与 D，观察只改夹角时内角怎样变化。比较 A 与 C、B 与 D，观察只改 BD 长度时相邻边怎样变化。

切到 D 组，调整 AO / AC 或 BO / BD，观察外框变形时，里面是否一直是正方形。

为什么中点四边形一定是平行四边形？

E、F 是 △ABC 两边的中点，所以 EF ∥ AC，且 EF = AC / 2。同理，GH ∥ AC，且 GH = AC / 2。FG、HE 都平行于 BD，长度等于 BD / 2。两组对边分别平行，所以 EFGH 是平行四边形。

在图中，射线 FE 与 OA 同向，射线 FG 与 OB 反向，因此 ∠EFG = 180° − ∠AOB。打开「中位线配色」，可以观察这些平行关系。

什么时候得到矩形、菱形或正方形？

AC 与 BD 等长时，EF 与 FG 等长，EFGH 是菱形。AC 与 BD 垂直时，EF 与 FG 垂直，EFGH 是矩形。两条对角线等长且垂直，恰好是 EFGH 为正方形的充要条件。
